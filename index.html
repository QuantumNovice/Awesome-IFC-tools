Awesome IFC Tools

A curated list of open-source tools, libraries, viewers, validators, and automation utilities for Industry Foundation Classes workflows.

Authoring Libraries Conversion Viewing Validation Servers Data Utilities

Authoring and Editing

Bonsai

Native IFC authoring platform built as a Blender add-on for modeling, drawings, schedules, costs, audits, and BIM data editing.

FreeCAD

Open-source parametric CAD and BIM application with IFC import, export, Python automation, and architecture-oriented workflows.

IfcPatch

IfcOpenShell utility for applying batch fixes and model transformations to IFC files.

IfcCSV

Exports IFC data to spreadsheets and imports edited tabular data back into IFC models.

COMPAS IFC

High-level Python interface for inspecting, editing, extracting geometry from, and creating IFC data.

Libraries and SDKs

IfcOpenShell

Open-source IFC library and geometry engine with C++ and Python APIs, schema support, and command-line tools.

xBIM Essentials

.NET toolkit for reading, writing, validating, and querying IFC and COBie data.

web-ifc

JavaScript and WebAssembly IFC parser for reading and writing IFC files in browsers and Node.js.

That Open Components

TypeScript components for browser-based BIM apps with Three.js, measurements, sections, and IFC workflows.

IfcPlusPlus

C++ IFC class model, STEP reader and writer, and sample Qt/OpenSceneGraph viewer.

XbimGeometry

Geometry engine used to compute and process IFC model geometry in .NET applications.

Conversion and Geometry

IfcConvert

Command-line converter from IFC to OBJ, DAE, GLB, SVG, STEP, IGES, XML, HDF5, and JSON variants.

xeokit-convert

Node.js CLI and library for converting AEC formats into xeokit's compact XKT format.

IfcCityJSON

IfcOpenShell utility for CityJSON and IFC interoperability in geospatial and city-model workflows.

Ifc2CA

Converts IFC structural analysis models to Code_Aster input files.

IFC-glTF

Client-side TypeScript library that converts IFC files to glTF with web-ifc and Three.js.

IFCConverter

Command-line converter that uses IfcOpenShell libraries to export IFC geometry to OBJ and STL.

Viewing and Web Apps

xeokit-bim-viewer

Browser-based 2D and 3D BIM viewer for IFC-derived models, BCF viewpoints, trees, sections, and large model navigation.

BIMsurfer

Open-source WebGL viewer for IFC models in the browser.

XbimXplorer

Windows WPF IFC viewer and desktop UI components built on the xBIM Toolkit.

XbimWebUI

TypeScript and JavaScript web components for presenting BIM models with xBIM.

web-ifc-viewer

Deprecated but useful reference implementation for IFC viewing tools built on web-ifc and Three.js.

IfcPlusPlus Viewer

Example IFC viewer application included with IfcPlusPlus, built with Qt and OpenSceneGraph.

Validation and QA

IfcTester

IDS authoring and validation tool that audits IFC models and exports console, HTML, JSON, ODS, or BCF reports.

IfcClash

CLI and library for clash detection across one or more IFC models using JSON clash-set definitions.

IfcDiff

Compares IFC models and reports differences in geometry, properties, and relationships.

Xbim.IDS.Validator

.NET library and console app for validating IFC and COBie models against IDS 1.0 specifications.

buildingSMART Validate

IFC validation service stack for syntax checks, schema checks, Gherkin rules, and related workflows.

Model Checker

Browser-based IFC and IDS validation application powered by Pyodide, IfcOpenShell, and IfcTester.

Collaboration and Servers

BIMserver

Open-source BIM server platform that stores IFC data as objects and supports checking, versioning, merging, and querying.

BIMserver JavaScript API

JavaScript client API for integrating web applications with BIMserver.

python-bimserver-client

Python client for automating BIMserver workflows and accessing IFC model data.

Data, BCF, and IDS Utilities

BCF library

IfcOpenShell package for reading and writing BCF-XML and interacting with BCF API workflows.

bSDD client

IfcOpenShell package for querying the buildingSMART Data Dictionary API.

bsdd-ids-validator

TypeScript library for validating ifcJSON data against bSDD and IDS-derived JSON schema rules.

IfcFM

Audits and converts IFC facility management data using COBie and FMH-EM workflows.

Ifc4D

Converts schedule and task data between IFC and project management formats.

Ifc5D

Quantity takeoff and cost-estimation utility for IFC-based 5D workflows.
